# Purpose

This project is meant as a python script that sends me an email with the top 10 matches for jobs everyday. I would like to use pipenv to create a virtual environment and use an api such as theirStacks to get job postings. The python script should run and prompt me for my preferred location. It should look for remote jobs as well as the preferred location, and there are no preferred job titles. The script should score each job based on the provided resume pdf in the directory on a scale of 0-100.
